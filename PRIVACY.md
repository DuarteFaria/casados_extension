# Opto Rank: Privacy Policy

*Last updated: 6 October 2026*

Opto Rank is an unofficial browser extension for [opto.sic.pt](https://opto.sic.pt). It is not affiliated with SIC or Opto.

## What is stored

- **An anonymous install ID.** A random identifier created when you install the extension and kept in the browser's extension storage. It is not linked to your name, email, Opto account or any other information about you.
- **Your ratings.** For each episode or movie you rate: the anonymous install ID, the content ID from Opto, the score (1–5) and when you voted.
- **Momentos o7 edits.** When you change an episode's Momentos o7 number: the anonymous install ID, the episode ID, the old and new value and when it changed. This log exists only to undo vandalism.

## What is not collected

No names, emails, Opto account details, passwords, browsing history, location, or anything you watch that you don't rate. The extension only runs on opto.sic.pt.

## Where it goes

Ratings are stored in a database hosted by [Convex](https://www.convex.dev) in the EU (Ireland). Averages and Momentos o7 numbers are public to everyone who uses the extension; individual votes are never shown. The extension also reads Opto's public catalogue (episode titles and IDs) from opto.sic.pt.

Data is not sold, shared with third parties or used for advertising.

## Deleting your data

Uninstalling the extension deletes the install ID from your browser. Your past votes remain only as anonymous numbers in the averages. To have them removed, open an issue on the project's GitHub repository or contact the developer, and include your install ID if you have it.

## Política de privacidade (resumo)

A Opto Rank é uma extensão não oficial, sem ligação à SIC ou à Opto. Guarda apenas um identificador anónimo e aleatório da instalação, as tuas notas (1–5) e as alterações aos Momentos o7. Não recolhe nome, email, conta da Opto nem histórico de navegação. Os dados ficam numa base de dados Convex na UE (Irlanda), não são vendidos nem partilhados, e só as médias são públicas. Desinstalar a extensão apaga o identificador do teu browser.
